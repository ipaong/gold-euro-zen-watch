# XAUEUR Signal Lab — แผนงานรอบแรก (Phase 1)

แอปช่วยตัดสินใจเทรด XAUEUR (ทองคำสกุลยูโร) บน timeframe M15 พยากรณ์ 5 แท่งถัดไป (~75 นาที)
ด้วย "นักวิเคราะห์ 5 คน" แล้วสรุปเป็น ซื้อ / ขาย / รอ — ไม่มีการส่งคำสั่งเทรดอัตโนมัติ

รอบนี้ทำ Phase 1 เท่านั้น: หน้าจอครบทุกหน้า + เครื่องยนต์พยากรณ์ที่คำนวณจริง + ข้อมูลเดโมสมจริง
เก็บข้อมูลในเบราว์เซอร์ (ยังไม่ต่อฐานข้อมูล) โครงสร้างโค้ดออกแบบให้สลับไปใช้ฐานข้อมูลจริง/ข้อมูลจริงได้ทีหลัง

ภาษาในแอป: ไทยทั้งหมด

## หน้าจอที่จะได้

1. **หน้าแรก (แดชบอร์ด)** — เรียงตามความสำคัญ
   - ราคา XAUEUR ปัจจุบัน, % เปลี่ยนแปลง, เวลาอัปเดตล่าสุด, สถานะตลาด
   - การ์ดใหญ่สุด: **สัญญาณรวม** 🟢 ซื้อ / 🔴 ขาย / ⚪ รอ + "โมเดลเห็นด้วย 4/5" + ความมั่นใจ % + ระดับความเสี่ยงข่าว
   - กราฟแท่งเทียน: แท่งจริงสีทึบ, 5 แท่งพยากรณ์โปร่งแสง + เส้นแบ่ง "จากนี้คือการพยากรณ์"
   - การ์ดโมเดล 5 ใบ (แตะเพื่อดูรายละเอียด)
   - "เกิดอะไรขึ้น?" / "ทำไมถึงซื้อ?" / "อะไรจะทำให้ผิดพลาด?" เป็นภาษาคนธรรมดา
   - 5 ฉากทัศน์อนาคต พร้อมลูกศร ↑↓ และ "น้ำหนักฉากทัศน์ %"
   - การ์ดวางแผนเทรด: แนวรับ/แนวต้านใกล้ ๆ, โซนที่ถือว่าคิดผิด, ATR, ระดับความเสี่ยง
   - ปฏิทินข่าวสำคัญที่กำลังจะมา + คำเตือน "ข่าวแรงอีก 18 นาที"
   - สรุปความแม่นล่าสุดแบบย่อ

2. **หน้าย้อนเวลา (Time Machine)** — เลือกวัน–เวลาในอดีต ระบบจะเห็นข้อมูลแค่ถึงเวลานั้น
   กด "ล็อกการพยากรณ์" → กด "เปิดเผยอนาคต" → เทียบพยากรณ์กับของจริงและให้คะแนน

3. **หน้าสมุดบันทึกการพยากรณ์** — รายการพยากรณ์ทั้งหมด เปิดดูย้อนหลังได้ตรงตามที่เห็นตอนนั้น (แก้ไม่ได้)

4. **หน้าคะแนนโมเดล** — ความแม่นของแต่ละโมเดลและของสัญญาณรวม, เลือกช่วง 20 / 50 / 100 / ทั้งหมด,
   แยกความแม่นฝั่งซื้อ–ขาย, ความถี่ที่บอก "รอ", ความมั่นใจเทียบกับความแม่นจริง

5. **หน้าข่าว & มหภาค** — ทิศทางทอง, ทิศทางยูโร, ผลรวมต่อ XAUEUR, ปฏิทินเศรษฐกิจ (🔴🟡⚪)

6. **หน้าตั้งค่า** — เกณฑ์ความมั่นใจ, จำนวนโมเดลขั้นต่ำที่ต้องเห็นด้วย, ช่วงเวลาเลี่ยงข่าวแรง
   (คู่เงินและ timeframe ล็อกไว้ที่ XAUEUR / M15)

7. **หน้าจอต้อนรับครั้งแรก** — อธิบายสั้น ๆ ว่าแอปทำอะไร ไม่ทำอะไร แล้วกด "เริ่มโหมดเดโม"

## กฎสำคัญที่จะเขียนลงในระบบ

- **ไม่บังคับให้เกิดสัญญาณ** — 3/5 เสียงไม่ได้แปลว่าซื้อทันที ต้องผ่านด่านคุณภาพ:
  จำนวนเสียงเห็นด้วย ≥ เกณฑ์, ความมั่นใจเฉลี่ยเหนือเกณฑ์, ข้อมูลสดพอ, ไม่มีแหล่งข้อมูลล่ม,
  ไม่มีข่าวแรงใกล้เกินไป, โมเดลไม่ขัดแย้งรุนแรง — ไม่ผ่านข้อไหนก็ตอบ **รอ** พร้อมบอกเหตุผลว่าติดข้อใด
- **ไม่ปั้นข่าว** — ยังไม่ต่อข่าวจริง จึงติดป้าย "ข่าวเดโม" ชัดเจนทุกจุด และทั้งแอปติดป้าย "ข้อมูลเดโม"
- **ราคาพยากรณ์ไม่ได้มาจาก AI เดา** — ใช้สูตรคำนวณที่ทำซ้ำได้ (สุ่มแบบมีเมล็ดคงที่ + ATR + ทิศทางเทรนด์)
  ผลลัพธ์เดิมให้ค่าเดิมเสมอ
- **พยากรณ์ที่ล็อกแล้วแก้ไม่ได้** — เก็บถาวร แล้วให้คะแนนเมื่อของจริงมาถึง
- ไม่ใช้คำว่า "การันตี" หรือ "ชัวร์" ที่ไหนเลย

ออกแบบมือถือก่อน มีแถบเมนูล่าง 5 ปุ่ม แล้วขยายเป็นหลายคอลัมน์บนจอใหญ่

## รายละเอียดทางเทคนิค

- TanStack Start + React + TypeScript, Tailwind v4, โทเคนสีทั้งหมดใน `src/styles.css`
- แยกชั้นชัดเจน:
  - `src/lib/market/` — `MarketDataProvider` (อินเทอร์เฟซ) + `MockXaueurProvider` สร้างแท่งเทียนสังเคราะห์
    ครอบทั้งขาขึ้น/ขาลง/ออกข้าง/เบรกเอาต์/ผันผวนสูง พร้อมฟังก์ชัน `getCandlesUpTo(timestamp)` กันข้อมูลรั่วจากอนาคต
  - `src/lib/indicators/` — EMA 20/50/200, RSI, MACD, ATR, swing high/low, แนวรับแนวต้าน
  - `src/lib/models/` — 5 ไฟล์: trend, momentum, technical, news, ensemble แต่ละตัวคืน
    `{ direction, confidence, forecastCandles, summary, factors, risks }`
  - `src/lib/forecast/` — เครื่องยนต์สร้าง 5 ฉากทัศน์ + แท่งพยากรณ์ (deterministic, seeded)
  - `src/lib/consensus/` — ด่านคุณภาพสัญญาณ
  - `src/lib/news/` — `NewsProvider` + `MockNewsProvider` (ปฏิทินเศรษฐกิจ EUR/USD ติดป้ายเดโม)
  - `src/lib/analysis/` — อินเทอร์เฟซ `AnalysisProvider` เตรียมไว้ต่อ AI ทีหลัง (รอบนี้ใช้ตัวสรุปแบบเทมเพลตภาษาไทย)
  - `src/lib/scoring/` — ให้คะแนน: ความแม่นทิศทาง, MAE, ค่าคลาดเคลื่อนราคาปิด/สูง/ต่ำ, แม่นรายแท่ง
  - `src/lib/store/` — เก็บพยากรณ์/ผลคะแนน/ตั้งค่าใน localStorage ผ่านอินเทอร์เฟซเดียว
    (Phase 2 เปลี่ยนเป็นฐานข้อมูลได้โดยไม่แตะ UI)
- กราฟแท่งเทียนเขียนเป็นคอมโพเนนต์ SVG ของเราเอง (คุมความโปร่งแสงของแท่งพยากรณ์ได้ตรงจุด)
- เส้นทาง: `/`, `/time-machine`, `/journal`, `/journal/$id`, `/performance`, `/news`, `/settings`
- ทุกไฟล์เล็ก แยกคอมโพเนนต์ ใช้ shadcn ที่มีอยู่แล้ว
- ทุกปุ่มที่เห็นต้องใช้งานได้ ถ้ายังไม่พร้อมให้ขึ้น "เร็ว ๆ นี้"
- เพาะข้อมูลพยากรณ์ย้อนหลังไว้พอให้หน้าคะแนนดูมีความหมาย ติดป้าย "เดโม" ทุกแถว
